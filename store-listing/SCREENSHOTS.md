# Store Listing Screenshots

To provide a great user experience on the Play Store, capture the following screenshots from a device or emulator:

## Required Scenes
1. **Login Screen**: Showing the "Sign in with Google" button and legal links.
2. **Verse Themes**: The main dashboard showing theme cards.
3. **Verse List**: Inside a theme, showing saved verses.
4. **Personal Notes**: The notes grid view.
5. **Note Editor**: Showing rich text and Bible reference detection.
6. **Daily Tracker**: The calendar view with sealed/unsealed days.
7. **Daily Record Editor**: Tracking reading and prayer time.
8. **Share Import**: The dialog that appears when sharing text to FaithFlow.

## Dimensions
- **Phone**: At least 2 screenshots. 1080 x 1920 or 1440 x 2560.
- **7-inch Tablet**: (Optional) 1200 x 1920.
- **10-inch Tablet**: (Optional) 1600 x 2560.

## Graphic Assets
- **App Icon**: 512 x 512 PNG (Use `app/src/main/ic_launcher-playstore.png`).
- **Feature Graphic**: 1024 x 500 PNG.
